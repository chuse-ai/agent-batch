# agent-batch

Run hundreds of one-off agent jobs unattended, each with a result contract. On your own machines first, spilling over to Cloudflare® Workers.

## Development

- Check everything is ready:

```bash
vp run ready
```

- Run the tests:

```bash
vp run -r test
```

- Build the monorepo:

```bash
vp run -r build
```

- Run the development server:

```bash
vp run dev
```
