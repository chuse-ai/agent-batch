# Vite+ as the toolchain, defaults first

The repo is generated with `vp create` and uses Vite+ (`vp check`, `vp test`, `vp pack`, `vp run`, commit hooks) with its defaults; hub and runner are generated by create-cloudflare into `apps/`, the CLI by `vp create vite:library` into `packages/`. Cloudflare's `@cloudflare/vitest-plugin` runs Worker tests under the Vitest that Vite+ ships, which removed the reason for ADR 0002. We take tool defaults as they come and deviate only by explicit decision, so the setup stays easy to upgrade and to recognise.

Approved deviations:

- `minimumReleaseAge: 1440` with no exemptions, including for Vite+ itself: a one-day delay is the cheapest guard against a compromised release for software that runs unattended with users' API keys.
- `allowBuilds` approving `workerd` and `esbuild`, which wrangler needs; pnpm requires an explicit answer.

This supersedes ADR 0001 (packages now link through Vite+'s dependency-ordered, cached builds) and ADR 0002.
