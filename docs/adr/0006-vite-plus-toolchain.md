# Vite+ as the toolchain, defaults first

The repo is generated with `vp create` and uses Vite+ (`vp check`, `vp test`, `vp pack`, `vp run`, commit hooks) with its defaults; hub and runner are generated by create-cloudflare into `apps/`, the CLI by `vp create vite:library` into `packages/`. Cloudflare's `@cloudflare/vitest-plugin`, for tests that run inside a Worker, supports the Vitest that Vite+ ships, which removed the reason for ADR 0002; the hub's tests start the Workers from Node with Wrangler's test harness instead (ADR 0003). We take tool defaults as they come and deviate only by explicit decision, so the setup stays easy to upgrade and to recognise.

Approved deviations:

- `minimumReleaseAge: 1440` with no exemptions, including for Vite+ itself: a one-day delay is the cheapest guard against a compromised release for software that runs unattended with users' API keys.
- `allowBuilds` approving `workerd` and `esbuild`, which wrangler needs, and denying `cpu-features`, `protobufjs` and `ssh2`, whose install scripts Testcontainers does not need; pnpm requires an explicit answer.
- Hub and runner follow Vite+'s templates where they differ from create-cloudflare's: they are ES modules (`"type": "module"`) and import other files by their `.ts` names (`allowImportingTsExtensions`). Settings the scaffold adds that change nothing here are removed: JSX and JavaScript options, TypeScript defaults, ignore rules the root `.gitignore` already covers, the `start` script that repeats `dev`, and the Wrangler configs' commented-out examples other than Smart Placement.
- The hub's test files run one at a time (`fileParallelism: false`), because they share one Postgres and each clears it before starting.

This supersedes ADR 0001 and ADR 0002. The private `contract` package exports its TypeScript source and has no build: it is never published, and everything that uses it compiles TypeScript itself (Wrangler for the Workers, Vitest for tests), so checks and tests run without building it first and the scaffold's `ready` script works unchanged. A package that is published is built with `vp pack`.
